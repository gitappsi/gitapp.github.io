# GitApp — Git brez panike

Statična slovenska stran za https://gitapp.si/.

## Vsebina

4 interaktivna učna orodja, 16 vodičev z izvirnimi shemami, informacijske strani, zemljevid strani, robots.txt in stran 404.

## Objava

Vse datoteke iz tega arhiva naloži neposredno v koren veje `main`, ne v dodatno podmapo. Arhiv pred nalaganjem razširi. V nastavitvah GitHub Pages izberi vejo `main` in korensko mapo. Domena v datoteki `CNAME` je `gitapp.si`.

## Izvedba

Stran je zgrajena z Node.js 26.13.1. Na gostovanju se objavi statični rezultat; strežnik Node.js ni potreben. Orodja uporabljajo module JavaScript v brskalniku. Za uporabo ni prijave ali dostopnih žetonov.

## Kontakt

Javni kanal za popravke je povezan na strani `stik.html`. Ne objavljaj zasebne kode, gesel ali osebnih podatkov. Zasebni obrazec in e-poštni predal nista del te izvedbe.

## Oglasi

Rezervirani prostori so skriti. Oglasna koda in tuji identifikatorji niso vključeni. Pred morebitnim oglaševanjem je treba urediti dejanskega ponudnika, politiko in potrebno soglasje.

## Preverjanje

47 avtomatskih preizkusov, vključno s šestimi primerjavami z dejanskim Gitom. Preverjene so notranje povezave, 19 zunanjih povezav ter prikazi širine 320, 390 in 1280 slikovnih pik. Tri reprezentativne strani so brez napak in opozoril pri preverjanju podatkov Schema.org.
